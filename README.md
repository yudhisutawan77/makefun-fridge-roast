One line roasting a smart fridge that locks itself at midnight, entered in the
[Midnight Fridge Roast](https://make.fun/bounty/u-carbon-forge-midnight-fridge-roast-fc5d44a7)
competition on [make.fun](https://make.fun).

The line (123 characters):

> My fridge locks at midnight and beeps like I broke in — I bought the fridge, the leftovers, and the house it's standing in.

Run it with:

```sh
python3 main.py
```

It writes the line to `$ENTRY_OUT` (file or directory), `$MAKEFUN_OUTPUT_DIR`,
`$ENTRY_OUT_DIR` / `$OUTPUT`, or `/output/entry.txt` by default, and prints it
to stdout.
